The Whole Project in One Page

The version to say out loud.

Binder Sniffer watches one app's IPC from the inside. We flip a single pointer so the app's binder calls pass through our code, copy each notification's Parcel as it heads to the kernel, decode it in place, and log the title and text — then forward the call so nothing breaks.

Phase 1 — Install & intercept (live, on the device)

  1. An injector uses ptrace to make the already-running app load our library (libbshook.so) into itself.
  2. The library's constructor walks libbinder's ELF tables, finds the GOT slot for ioctl, makes the page writable, and overwrites it with our my_ioctl. The hook is now installed.
  3. Every ioctl libbinder makes now enters my_ioctl first. It forwards everything untouched, only pausing on BINDER_WRITE_READ (the one that carries transactions).
  4. For those, we walk the write command stream; for each BC_TRANSACTION we follow data.ptr.buffer to the Parcel and check whether it targets INotificationManager.

Phase 2 — Decode & log (same thread, in place)

  1. A matching Parcel goes to bs_decode_enqueue: read the interface token, then the arguments in order (keep the package), then scan the extras for android.title and android.text.
  2. Print pkg / title / text with __android_log_print. Read it live with adb logcat -s binder-sniffer.
  3. Offline mirror: the identical decoder runs on a saved .bin in a host harness on the Mac — that's how it was built and verified before ever trusting it on-device.

Why it's safe: the decoder only reads memory and never calls ioctl, so it can't re-enter the hook; and logging goes to logd over a socket, not through /dev/binder. The app never notices.
